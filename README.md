# HackBio_Bash-Course_ProjectTask
Completed a foundational Bash scripting project as part of the HackBio Internship, focusing on Linux command-line operations and basic bioinformatics workflows.

The project covered file and directory management, sequence data retrieval, duplicate-file identification, nucleotide motif searches, and extraction of information from FASTA and GenBank files using Bash, grep, awk, and related utilities.
